# kassamoney.com

Plain static pages for the Kassa website: home, privacy policy, support. No build step, no scripts except the
coffee-link switch in `support.html`, no cookies, no analytics.

Deploy: point any static host (Cloudflare Pages, GitHub Pages, Netlify) at this folder.
The privacy page repeats the in-app Privacy page (`ui/settings/AboutPages.kt`); change both together.
